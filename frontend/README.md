# Frontend (Next.js + TypeScript + Tailwind + shadcn/ui)

Scaffolded in Phase 3, after the architecture and schema are approved, with:

```bash
npx create-next-app@latest . --ts --tailwind --app --src-dir --eslint
npx shadcn@latest init
```

Planned routes (sidebar order): `/dashboard`, `/companies`, `/contacts`, `/taxonomy`, `/segments`, `/templates`, `/campaigns/new`, `/campaigns`, `/analytics`, `/sending-accounts`, `/settings`.
